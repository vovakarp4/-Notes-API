# Notes API

Учебное веб-приложение для хранения заметок с намеренными уязвимостями (OWASP Top 10).

⚠️ **Приложение намеренно уязвимо. Запускать только локально или в изолированной среде.**

## Запуск

    pip install flask
    python main.py

Открыть: http://localhost:5000

## Тестовые пользователи

| Логин | Пароль | Роль |
|---|---|---|
| admin | admin123 | админ (заметка с флагом) |
| alice | password | обычный |
| bob   | qwerty   | обычный |

## Уязвимости

| Уязвимость | Где | Что позволяет |
|---|---|---|
| Command Injection | `/ping` | выполнить команду ОС |
| SSTI | `/render` | выполнить Python-код |
| Debug RCE | `debug=True` | захватить сервер |
| SQL-инъекция | `/login` | войти без пароля |
| SQL-инъекция | cookie `uid` | слить данные |
| IDOR | `/note/<id>` | читать чужие заметки |
| Утечка хешей | `/api/users` | узнать все пароли |
| XSS | `/note/<id>` | выполнить JS в браузере |
